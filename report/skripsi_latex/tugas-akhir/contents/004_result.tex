        \subsection{Formulasi Model untuk Tiap Konfigurasi}\label{subsec:model per config}
        % (P2) Pers. 2.21 ditulis eksplisit dengan angka. Nilai eta dan tau dari
        % data/processed/risk_limits_bank_train_seed42_N5000.json (6 angka penting).
        % SUMBER: data/processed/risk_limits_bank_train_seed42_N5000.json
        % SUMBER: results/tables/audit_data.md
        Model untuk definisi biaya bruto dengan batas proporsi DJPPR:
        \begin{equation}\label{eq:model gross djppr}
            \begin{aligned}
                \min_{\mathbf{w}} \quad & \overline{\mathrm{Cost}}(\mathbf{w}) = \frac{1}{N}\sum_{s=1}^{N}\sum_{i=1}^{7} w_i C_{i,s}\\
                \text{dengan kendala} \quad & J_{\mathrm{MCCaR}}(\mathbf{w}) \le 0{,}0681943,\\
                & \mathrm{CCaR}_{0{,}95}(\mathbf{w}) \le 1{,}08602,\\
                & \textstyle\sum_{i=1}^{7} w_i = 1,\\
                & 0{,}425 \le w_1 \le 0{,}490,\quad 0{,}100 \le w_2 \le 0{,}125,\quad 0{,}130 \le w_3 \le 0{,}165,\\
                & 0{,}130 \le w_4 \le 0{,}155,\quad 0{,}015 \le w_5 \le 0{,}030,\quad 0{,}050 \le w_6 \le 0{,}085,\\
                & 0{,}030 \le w_7 \le 0{,}055.
            \end{aligned}
        \end{equation}
        % Konfigurasi gross_free: kendala proporsi diganti 0 <= w_i <= 1.
        % Konfigurasi interest_*: C_{i,s} diganti C^I_{i,s} (Pers. 2.3),
        % eta = 0,174188 dan tau = 0,0649691.
        % Tuliskan ketiga model lainnya dengan pola yang sama (seperti TA rujukan),
        % lalu jelaskan penanganan kendala (proyeksi + penalti, Pers. 2.23–2.24,
        % rho_J = rho_R = 10^6).
